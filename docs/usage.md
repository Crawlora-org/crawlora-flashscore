# Flashscore API endpoint reference and client usage

This reference lists all 54 public Flashscore API endpoints exposed by the JavaScript/TypeScript, Python, Go, Ruby, Java, PHP, and Rust clients, including the `@crawlora-org/flashscore`, `crawlora-flashscore`, and `crawlora-flashscore` packages. The clients call Crawlora's hosted API. Set `CRAWLORA_API_KEY` to a key for your Crawlora account before making requests. Service usage is billed under that account. These clients do not run a browser or scrape Flashscore locally; Crawlora is independent from and not endorsed by Flashscore or its owners.

The package tracks the public API contract revision `sha256:fd1c70a1b050d86c9e738a62dd14cde04b8a3ce00eb3e281b1d248c1ccdb2e92` bundled with release `0.3.6`. Maintainers can preview daily contract updates with the repository's `Sync live API contract` workflow; unchanged contracts do not produce package releases.

All language packages expose the selected public API operations in the bundled contract. JavaScript uses camelCase methods, Python and Rust use snake_case methods. JavaScript, Python, and Rust methods are grouped under `flashscore`; Rust uses typed parameter structs and returns the complete HTTP response.

## Client forms

- JavaScript: import `FlashscoreClient` (also exported as `Client`) from `@crawlora-org/flashscore`; use `new FlashscoreClient({ apiKey })` and `await client.method({ ... })`.
- Python: import `FlashscoreClient` (also exported as `Client`) from `crawlora_flashscore`; use `with FlashscoreClient(api_key=...) as client` and `client.method(...)`.
- Python async class: `AsyncFlashscoreClient`, used with `async with` and `await`.
- Rust: add `crawlora-flashscore` with Cargo; import `Client` and the generated operation parameter struct, then call `client.flashscore.<snake_case_method>(params).await`. See the [Rust example](https://github.com/Crawlora-org/crawlora-flashscore/blob/main/rust/examples/quick_start.rs).

See the package READMEs for installation details. Keep API keys in environment variables or a secret store; do not commit them.
